# Mitwirken

Ein Issue beschreibt Problem, Scope und überprüfbare Akzeptanzkriterien. Branch `codex/<issue>-<thema>`, fokussierter PR mit `Closes #...`, Testevidenz und Grenzen. Keine Bilder, Modelle, Tokens oder generierte Downloads committen.

Domain importiert nur Standardbibliothek; Application nur eigene Domain/Ports. Konkrete Adapter ausschließlich im Composition Root verdrahten. Neue Formate/Modelle erst nach Schutzgrenzen und Integrationstest. Nie einen Scanner still auf `continue-on-error` setzen. Bei Dependencies Lockdateien erneuern und Diff prüfen.
